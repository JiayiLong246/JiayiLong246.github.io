直接使用

在线刷题 · 打开本次题目与答案阅读版 · 下载完整工具包 v0.5.0

阅读版是本次上传文件的快照。在线刷题页每分钟检查公开题库更新，练习中会显示更新按钮，可自行选择加载时机。页面部署与缓存可能产生延迟。

维护者首次配置

  1. 下载工具包，覆盖原来加载的 extension 文件夹，在浏览器扩展管理页重新加载并刷新学校练习页面。
  2. 以 JiayiLong246 登录 GitHub，打开 创建 fine-grained personal access token 页面，选择一个到期时间。
  3. Repository access 选择 Only select repositories，再选择 JiayiLong246.github.io。在 Repository permissions 中将 Contents 设为 Read and write，创建 token。可参阅 GitHub 官方说明。
  4. 打开插件的“GitHub 公开题库同步”，在密码输入框填入 token，勾选“每套完成后自动同步 GitHub”，点击“保存同步配置”，允许访问 GitHub API。
  5. 点击“立即同步累计题库”，确认显示同步成功。之后每套答案采集完成后约10秒安排一次同步。

token 保存在这台电脑的扩展本地存储，导出的诊断日志和公开题库只包含学习与运行字段。请在扩展中填写凭据，不要把凭据发到聊天或提交到仓库。到期后在插件里更新凭据即可。

同步和故障处理

公开文件位于仓库的 zhixi/questions.json，与远端已有题目合并，重复题去重，答案冲突保留待核对。没有新增或答案变化时跳过提交。

插件内可查看最近同步结果。网络或权限失败时，采集记录仍在本机，可点击“立即同步累计题库”重试。需要排查时，导出诊断日志发给维护者。自动练习与答案识别的完整操作步骤见工具包内指南。
